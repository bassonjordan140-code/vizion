# Grille tarifaire EDF Reunion

Ce depot contient le classeur de travail consolide pour la grille tarifaire EDF Reunion 2020-2026, avec :

- les prix consolides par tarif et periode ;
- les plages horaires horosaisonnieres ;
- le calcul des tranches horotarifaires sur des pas de temps de 10 minutes ;
- la correspondance site, tarif et puissance souscrite selon l'historique disponible.

## Fichier principal

`outputs/grille_tarifaire/grille_tarifaire_edf_reunion_2020_2026.xlsx`
