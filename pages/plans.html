Plans d'évacuation

Repérez les chambres sur les plans d'évacuation : un type de chambre, une couleur. Cette étape est facultative.

1. Types de chambres

Ajoutez les types de pièces de l'hôtel. Une couleur est attribuée automatiquement à chacun.

2. Plans d'évacuation

Photographiez un plan (un par niveau ou par bâtiment si besoin), puis posez les points de couleur sur les chambres.
