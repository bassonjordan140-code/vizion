ViZion — Politique de confidentialité

Dernière mise à jour : 28 octobre 2026

ViZion est une application d'audit énergétique destinée aux équipes de Green Tech qui visitent des hôtels. Cette page explique quelles informations l'application utilise, où elles sont conservées et ce que vous pouvez en faire.

1. L'essentiel

  • Les données de vos audits restent sur votre appareil.
  • ViZion n'a pas de compte utilisateur et n'utilise aucun serveur ViZion pour stocker vos audits.
  • Il n'y a aucune publicité, aucun outil de statistiques ni de suivi, et aucune revente de données.

2. Les informations que vous saisissez

Au fil d'un audit, vous pouvez enregistrer dans l'application :

  • les informations du site audité (nom de l'hôtel, adresse, commune, type de construction) ;
  • les coordonnées des personnes présentes à l'audit (rôle, nom, téléphone, e-mail) ;
  • les fiches d'équipements et de locaux (puissances, nombres, observations) ;
  • des photos d'équipements et de plans d'évacuation, ainsi que les points de couleur posés sur ces plans.

Ces informations sont enregistrées dans le stockage interne de l'application, sur votre appareil. L'éditeur n'y a pas accès.

3. Autorisations demandées

  • Appareil photo : uniquement pour photographier les équipements et les plans d'évacuation. Les photos sont conservées dans l'application.
  • Internet : pour charger la police de caractères de l'application et pour la fonction facultative décrite au point 5.

4. Rapports et sauvegardes

Lorsque vous générez un rapport ou une sauvegarde, l'application crée un fichier (Excel, données JSON, photos, archive ZIP) et l'enregistre dans le dossier « Téléchargements » de votre appareil, ou vous propose de le partager via le menu de partage d'Android. Vous choisissez vous-même ce que vous en faites : l'application n'envoie pas ces fichiers automatiquement.

5. Copie facultative sur GitHub

Une fonction facultative, désactivée par défaut, permet d'envoyer une copie du rapport (fichier Excel, données JSON, photos) vers un dépôt GitHub. Elle ne fonctionne que si un utilisateur autorisé saisit lui-même un jeton d'accès personnel GitHub dans l'application. Ce jeton est conservé uniquement sur l'appareil. Les fichiers envoyés sont alors traités par GitHub selon sa propre politique de confidentialité (déclaration de confidentialité de GitHub). Sans jeton, aucune donnée de ce type ne quitte l'appareil.

6. Services tiers

  • Google Fonts : la police « Manrope » est chargée depuis les serveurs de Google, qui reçoit alors l'adresse IP de l'appareil, comme pour tout contenu chargé sur Internet.
  • Google Play : l'application est distribuée via Google Play, soumis à la politique de Google.
  • GitHub : uniquement pour la fonction facultative du point 5.

7. Conservation et suppression

Vos données restent sur l'appareil tant que vous ne les supprimez pas. Vous pouvez supprimer un hôtel (et toutes ses données) depuis l'écran « Ouvrir un audit », ou tout effacer en supprimant les données de l'application dans les réglages d'Android, ou en la désinstallant. Les rapports et sauvegardes que vous avez téléchargés sont des fichiers à vous : supprimez-les depuis votre appareil.

8. Sécurité

Les données étant stockées localement, leur sécurité dépend aussi de celle de votre appareil (verrouillage de l'écran, mises à jour). Pensez à faire des sauvegardes régulières et à les conserver en lieu sûr.

9. Enfants

ViZion est un outil professionnel. Il ne s'adresse pas aux enfants et ne collecte aucune donnée à leur sujet.

10. Vos droits et nous contacter

L'éditeur ne collectant pas vos données, vous les consultez, modifiez et supprimez directement dans l'application. Pour toute question sur cette politique, contactez Green Tech à l'adresse e-mail indiquée sur la fiche de l'application sur Google Play.

11. Modifications

Cette politique peut évoluer avec l'application. La date de dernière mise à jour figure en haut de cette page.
